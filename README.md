# battaniyenin-omuz-veya-ayak-ikilemi-turkiye-buyuk-millet-meclisi
Battaniyenin ya omuzu ya ayağı örtmesini resmi yasama krizi, milli vücut kvorumu ve Meclis örtü protokolü sayan; yorganı genel kurul, üşümeyi muhalefet şerhi, 'biraz çekince kapanır' cümlesini torba kanun ilan eden Meclis. Gerçekten çalışır. Ayaklar artık milletvekilidir.
